01 · Principles

Four rules the palette encodes

01

Moving is not news

Work in flight is drawn in neutral ink. A busy line should look calm, so only a finished, verified result earns green.

02

One warm colour

Ember means a person should look: a spec to approve, a held PR, a failure, Stop the line. Nothing else on the page is warm, so a problem is the first thing you see.

03

Read it like a log

Ids, clocks and figures are monospaced and tabular. Numbers line up, and a change in one is visible without reading.

04

Shape, then colour, then motion

Every state has its own face, hatch and belt, so the line reads in greyscale. Colour confirms; motion adds life and always stops when asked.

02 · Colour

Roles, not colours

Components use role names only. Each theme gives every role a value, so switching Paper and Ink is one attribute. Ratios are measured live against the page ground for the theme you are viewing.

03 · Type

An editorial serif over a technical sans

Instrument Serif gives the console a voice; Geist keeps controls quiet; Geist Mono makes anything factual look like it came from the system. The .t-* classes in tokens.css apply each role.

04 · Stations

Eight stages, six states, one chassis

The tool on top says what the stage does. The face, beacon, hatch and belt say how it is doing. Drawn at 168 wide, so eight make one continuous belt across the console; here they are shown at 140.

05 · Anatomy

What each part tells you

1 2 3 4 5
  1. Tool

    What the stage does: a dish that listens, a funnel that sorts, a compass that draws a circle, a hammer, a boom barrier, a lens that reads a page, a canary in a cage and a pen that signs. It moves only while the stage is working, and Review’s page and Verify’s card come up only when there is work.

  2. Beacon

    Ink while work is in flight, green once it has passed. When the station needs you it glows and flashes, under three times a second, and throws a few rays.

  3. Face

    An LED face, always dark in both themes. Eyes carry the state: shut, busy, glancing back, pleased, squinting, crossed out.

  4. Hatch

    Progress while working, a tick when passed, a left arrow when sending back, hazard stripes when blocked, FAULT when failed.

  5. Belt

    Runs forward while working, slower when passed, backwards when sending back, and stops when the station is idle, blocked or failed.

06 · Mark · proposal

Two letters, one stem, one ember

Martin Rogan’s initials in Instrument Serif. The R shares the M’s last stem, so the two letters read as one mark. The full stop is the ember that means “look here” on the console, and it signs the CV the same way.

07 · Using it

For whoever builds the console

<!-- tokens first; the theme is one attribute -->
<html data-theme="paper">
<link rel="stylesheet" href="tokens.css">
<script src="station.js"></script>

<!-- a button names the stage, so the drawing is decorative -->
<button aria-label="Gates: needs you. 2 PRs">
  <sf-station kind="gates" status="blocked" decorative></sf-station>
</button>

<!-- standalone, it names itself: "Build: working" -->
<sf-station kind="build" status="working"></sf-station>

/* in CSS, roles only */
.needs-you { border-left: var(--stroke-rule) solid var(--attn); }
.figure    { font-family: var(--font-mono); font-variant-numeric: tabular-nums; }
