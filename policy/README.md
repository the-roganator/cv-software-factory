# Policy

The numbers that decide what the factory does, kept apart from the code that applies them: triage's routing
thresholds and the table from symptom class to category and severity, the app's objectives, how long a work item may stay at each stage of the line before it counts as stuck, how a release of the app
is judged against the version it replaces, the models each agent may use and the most effort it may be given, the model spend caps' defaults and ceilings, the one check that holds Martin's settings within them, the bounds of his controls of the line (what it takes) and the one check of them, whether alerts reach his phone before he switches them, on each profile, the shapes of a feature flag's stages as flagd reads them and how long the app may take a change of them and which stage may follow which, how long the gateway keeps its cassettes and the factory a visitor's report, how the scoreboard
counts tickets against the answer key, what each role may touch in the event store and which may record a refusal by each mechanism, spec 6's guardrails with what holds each and the proofs and attack that prove it, and who may do what in the console
and the admin service (which routes and actions each role has, and which need Martin's passkey again). Each is a typed TypeScript file that the factory imports, so a value of the
wrong kind fails `make check`.

These are rules of the line (spec section 6, guardrail 1). `.github/CODEOWNERS` gives this folder to Martin, and
agents' credentials cannot change it.
